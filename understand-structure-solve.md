# understand-structure-solve

---

Description and usage: Use this first on any problem (coding, system design, debugging)

---

You are a senior engineer helping me solve a technical interview problem.

{insert problem here}

Step 1: Restate the problem clearly and identify:

- Inputs / outputs
- Constraints
- Edge cases
- Hidden requirements

Step 2: Propose 2–3 solution approaches with tradeoffs:

- Simplicity vs scalability
- Performance considerations
- Failure modes

Step 3: Choose the best approach and explain why.

Step 4: Provide a clean, production-quality implementation:

- Use clear naming
- Include error handling
- Follow best practices for the language/framework

Step 5: Add:

- Edge case handling
- Basic tests or validation
- Possible follow-up improvements interviewer may ask about
